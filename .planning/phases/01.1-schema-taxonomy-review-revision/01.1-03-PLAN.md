  <name>Task 1: Rewrite page.py with hybrid PageQuality, PageDependency, SectionContextEntry, and base_direction</name>
  <files>scholargt/schema/page.py</files>
  <action>
REWRITE `scholargt/schema/page.py`. The file must contain these models:

**1. PageQuality (updated -- hybrid replacement for categorical ScanQuality/Difficulty):**
A BaseModel with:
- `overall: Literal["low", "medium", "high"] | None` (default None) -- quick categorical for human annotation
- `is_scan: bool | None` (default None) -- scanned vs born-digital
- `artifacts: list[str]` (default_factory=list) -- specific quality issues: "bleed_through", "foxing", "skew", "margin_cropping", "water_damage", "faded_ink", "handwritten_overlay", etc. Free-form strings, documented recommended values.
- `difficulty_factors: list[str]` (default_factory=list) -- specific difficulty signals: "dense_footnotes", "multi_column", "mixed_language", "complex_typography", "poor_scan", "non_latin_script", etc. Replaces old Difficulty enum.
- `dpi_estimate: int | None` (default None) -- estimated DPI
- `contrast_ratio: float | None` (default None) -- estimated contrast
- `skew_angle: float | None` (default None) -- page skew in degrees
- `noise_level: float | None` (default None) -- noise estimate 0-1
- `ocr_confidence: float | None` (default None) -- mean OCR confidence if available

**2. PageDependency (NEW) -- Cross-page relationship metadata:**
A BaseModel with:
- `continues_from_previous: bool` (default False) -- some content continues from prior page
- `continues_to_next: bool` (default False) -- some content continues to next page
- `unresolved_markers: list[str]` (default_factory=list) -- body markers with no note on this page (endnote refs)
- `orphan_continuations: list[str]` (default_factory=list) -- note content with no marker on this page

**3. SectionContextEntry (NEW) -- Hierarchical section path entry:**
A BaseModel with:
- `section_id: str` -- reference to Section element in DocumentGT
- `title: str` -- section title text
- `level: int` -- nesting level (0 = top-level)
- `starts_on_this_page: bool` (default False)
- `ends_on_this_page: bool` (default False)

**4. PageGT (updated):**
Keep existing fields: schema_version, page_index, page_label, dimensions, regions, reading_order, verifications, model_config extra="allow".

Replace `quality: PageQuality | None` with the new hybrid PageQuality (same field name, new model).

Add new fields:
- `section_context: list[SectionContextEntry]` (default_factory=list) -- hierarchical section path for self-describing pages
- `page_dependency: PageDependency | None` (default None) -- cross-page dependency metadata
- `base_direction: Literal["ltr", "rtl"] | None` (default None) -- SFP-2: default text direction for this page

Keep the existing `_validate_reading_order` model_validator.

Import `Literal` from `typing`. Import `VerificationRecord` from base, `Region` from spatial, `SCHEMA_VERSION` from version. Do NOT import anything from labels.py directly (PageGT doesn't use label enums directly).

- `typeface_convention: str | None` (default None) -- expected typeface family (e.g., "rashi_script", "square_hebrew", "serif_9pt")

Detailed docstring: "A named reading stream or column in a multi-register document. Provides first-class identity for parallel text streams, commentary layers, bilingual columns, and multi-register layouts."

**4. DocumentGT (updated):**

- `note_schemas: list[NoteSchema]` (default_factory=list) -- document-level note numbering conventions (multiple simultaneous schemas supported)
- `citation_style: CitationStyle | None` (default None) -- document-level citation convention

REMOVE: `relationships: DocumentRelationships | None`. This field and the DocumentRelationships, FootnoteLink, CitationBibLink models are eliminated. Relationships are now embedded in elements (Note.body_marker, Citation.bib_entry_id, CrossReference.target_section_id).
