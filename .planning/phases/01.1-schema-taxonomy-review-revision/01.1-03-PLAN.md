  ```python
  class PageQuality(BaseModel):
      """Hybrid page quality assessment: categorical overview + numeric metrics + artifact flags.

      Replaces the old categorical-only ScanQuality and Difficulty enums.
      The categorical fields provide quick filtering; numeric metrics provide
      measurable data for downstream pipeline calibration.
      """
      overall: Literal["low", "medium", "high"] | None = Field(
          default=None, description="Quick categorical quality assessment"
      )
      is_scan: bool | None = Field(
          default=None, description="Whether this page is from a scan (vs born-digital)"
      )
      artifacts: list[str] = Field(
          default_factory=list,
          description="Specific quality artifacts (e.g., 'bleed_through', 'foxing', 'skew', 'noise', 'fading', 'warping')"
      )
      dpi_estimate: int | None = Field(
          default=None, description="Estimated DPI of the scan"
      )
      contrast_ratio: float | None = Field(
          default=None, description="Contrast ratio (0.0-1.0 normalized)"
      )
      skew_angle: float | None = Field(
          default=None, description="Page skew angle in degrees"
      )
      noise_level: float | None = Field(
          default=None, description="Noise level estimate (0.0-1.0 normalized)"
      )
      ocr_difficulty: Literal["low", "medium", "high"] | None = Field(
          default=None, description="OCR difficulty assessment"
      )
      difficulty_factors: list[str] = Field(
          default_factory=list,
          description="Factors affecting difficulty (e.g., 'foreign_terms', 'dense_footnotes', 'poor_contrast', 'mixed_scripts')"
      )
  ```

  **ADD PageDependency** model (per DECIDED Cross-Page Relationships):
  ```python
  class PageDependency(BaseModel):
      """Cross-page dependency metadata for self-describing pages.

      Declares what this page needs from adjacent pages, enabling partial
      GT annotation (page sampling) with awareness of cross-page elements.
      """
      continues_from_previous: bool = Field(
          default=False, description="True if content continues from previous page"
      )
      continues_to_next: bool = Field(
          default=False, description="True if content continues to next page"
      )
      unresolved_markers: list[str] = Field(
          default_factory=list,
          description="Note markers on this page whose content is on another page"
      )
      orphan_continuations: list[str] = Field(
          default_factory=list,
          description="Region IDs that are continuations without a preceding region"
      )
  ```

  **ADD SectionContextEntry** model (per DECIDED Section Context on Pages):
  ```python
  class SectionContextEntry(BaseModel):
      """A section active on this page, denormalized from DocumentGT.

      Provides hierarchical section path so each page is self-describing
      without requiring the full DocumentGT.
      """
      section_id: str = Field(description="Section element ID in DocumentGT")
      title: str = Field(description="Section title")
      level: int = Field(description="Nesting level (0 = top-level)")
      starts_on_this_page: bool = Field(
          default=False, description="True if section begins on this page"
      )
      ends_on_this_page: bool = Field(
          default=False, description="True if section ends on this page"
      )
  ```

  **UPDATE PageGT** — add two new fields:
  - `section_context: list[SectionContextEntry] = Field(default_factory=list, description="Sections active on this page (denormalized from DocumentGT)")`
  - `page_dependency: PageDependency | None = Field(default=None, description="Cross-page dependency metadata")`

  Place `section_context` after `quality` and `page_dependency` after `section_context` (before `verifications`).

  Remove imports of ScanQuality/Difficulty from labels if present (they are not currently imported directly, but verify). Keep all existing imports. The `Literal["low", "medium", "high"]` values are inline now, not from enums.
