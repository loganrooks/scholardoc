Fields: author, title, year, journal, volume, issue, pages, publisher, doi, isbn, url, edition, editor, translator, work_abbreviation. All optional except none required. Purpose: BibEntry needs richer bibliographic data than ParsedCitation provides.

4. **ToCEntry** (kept as-is) -- title, level, page_label, page_index.

5. **NoteSchema** (NEW) -- Document-level note numbering convention. Fields:
   - `schema_id: str` -- unique identifier
   - `marker_type: Literal["arabic", "roman_lower", "roman_upper", "alphabetical_lower", "alphabetical_upper", "symbolic", "custom"]`
   - `symbol_sequence: list[str] | None` (default None) -- for symbolic markers: ["*", "dagger", "double_dagger", "section", "parallel", "pilcrow"]
   - `reset_boundary: Literal["page", "chapter", "section", "essay", "document"] | None` (default None)
   - `placement: Literal["page_bottom", "end_of_chapter", "end_of_book", "margin"] | None` (default None)
   - `note_source: Literal["author", "translator", "editor"] | None` (default None)
   NoteSchema is a BaseModel, not a GTElement.

**Element models (inheriting GTElement, each with element_type Literal):**

6. **Note** (NEW, replaces Footnote+Endnote) -- `element_type: Literal["note"] = "note"`. Fields:
   - `body_marker: LocationRef` -- where reference marker appears in body text
   - `content_marker: LocationRef | None` (default None) -- where note content begins (important for endnotes)
   - `content: list[ContentSpan]` -- content spans (may cross pages)
   - `placement: Literal["page_bottom", "end_of_chapter", "end_of_book", "margin"]`
   - `scope: Literal["page", "chapter", "section", "essay", "document"] | None` (default None)
   - `note_source: Literal["author", "translator", "editor"] | None` (default None)
   - `marker_text: str | None` (default None) -- marker display text (e.g., "1", "*", "a")
   - `note_schema_id: str | None` (default None) -- reference to NoteSchema in DocumentGT

7. **Commentary** (NEW) -- `element_type: Literal["commentary"] = "commentary"`. Fields:
   - `source: str` -- who wrote the commentary (e.g., "Rashi", "editor")
   - `passage_ref: str` -- what passage it comments on (canonical coordinates)
   - `reference_system: ReferenceSystem` -- how it locates the passage
   - `target_location: LocationRef | None` (default None) -- optional precise location
   - `content: list[ContentSpan]` -- commentary content spans
   - `layer: str | None` (default None) -- commentary layer identifier (for multi-layer commentary)

8. **Citation** (updated) -- `element_type: Literal["citation"] = "citation"`. Replace `citation_type: CitationType` with:

   - `reference_system: ReferenceSystem | None` (default None) -- what coordinates locate the passage
   - Keep: raw_text, parsed (ParsedCitation), bib_entry_id, page, region_id

9. **BibEntry** (updated) -- `element_type: Literal["bibliography_entry"] = "bibliography_entry"`. Replace `parsed: ParsedCitation | None` with `record: BibliographicRecord | None`. Keep: raw_text, entry_index.

10. **Section** (kept as-is) -- element_type, title, level, page_start, page_end, children.

11. **SousRature** (kept as-is) -- element_type, text, page, region_id, char_offset, char_length.

12. **CrossReference** (kept as-is) -- element_type, raw_text, target_page, target_section_id, page, region_id.

13. **MarginalReference** (updated) -- Replace `ref_type: MarginalRefType` with `reference_system: ReferenceSystem`. Keep: element_type, raw_text, page, region_id.

14. **PageNumberAnnotation** (kept as-is) -- element_type, display_text, number_type, page_index.
