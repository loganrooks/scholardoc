## Accomplishments
- Rewrote PageQuality as hybrid model combining categorical assessment (overall, is_scan), free-form lists (artifacts, difficulty_factors), and numeric metrics (dpi, contrast, skew, noise, ocr_confidence)
- Added PageDependency (cross-page continues_from/to, unresolved_markers, orphan_continuations) and SectionContextEntry (hierarchical section path per page) to make pages self-describing
- Added base_direction (SFP-2) to PageGT for default text direction
- Created LayoutRegister (SFP-1) with full register metadata for multi-register document support (Talmud, bilingual editions, critical editions)
- Updated DocumentGT with registers, note_schemas, citation_style; removed DocumentRelationships/FootnoteLink/CitationBibLink
- Added NoteSchema uniqueness validator (warns on duplicate schema_id)

## Decisions Made
- PageQuality hybrid approach: categorical `overall` for quick human annotation, free-form `artifacts`/`difficulty_factors` lists for specific issues, optional numeric metrics for automated quality assessment
- LayoutRegister at document level with register_id back-reference at region level (Region.register_id from Plan 02 links to LayoutRegister.register_id)
- DocumentRelationships model eliminated entirely -- Note.body_marker, Citation.bib_entry_id, CrossReference.target_section_id embed relationships directly in elements
- NoteSchema validator uses warnings (not errors) consistent with the incremental annotation pattern established in Plan 02
