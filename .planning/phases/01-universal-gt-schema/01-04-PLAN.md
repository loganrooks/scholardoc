    **scholargt/validation/schema_gen.py**: JSON Schema generation.

    `generate_schema() -> dict`:
    - Use `pydantic.json_schema.models_json_schema()` with PageGT, DocumentGT, and GTProfile models in 'validation' mode
    - Add `$schema: "https://json-schema.org/draft/2020-12/schema"` and `version: SCHEMA_VERSION` to output
    - Set title to "ScholarGT Schema"
    - Return the schema dict

    `write_schema(output_path: Path | None = None) -> Path`:
    - Generate schema via generate_schema()
    - Write to `output_path` or default `scholargt/generated/schema.json`
    - Return the path written to

    Generate and commit `scholargt/generated/schema.json` as part of this task by running write_schema().

    **scholargt/validation/validator.py**: Config-aware GT validation.

    `ValidationResult(BaseModel)`:
    - `valid: bool`
    - `errors: list[str] = Field(default_factory=list)`
    - `warnings: list[str] = Field(default_factory=list)`

    `validate_page_gt(data: dict, profile: GTProfile | None = None) -> ValidationResult`:
    1. Schema validation: validate data against generated JSON Schema for PageGT (using jsonschema library). If no schema.json found, validate via Pydantic model_validate.
    2. If profile provided, check config-aware rules:
       - All region labels must be in profile.spatial_labels (warn on unknown, don't error — allows extension)
       - If profile.validation.require_reading_order, warn if reading_order is empty
       - If profile.validation.require_text, warn if any region has text=None
       - If profile.validation.require_bbox, error if any region has no bbox
    3. Structural checks (always run):
       - reading_order IDs should reference existing region IDs
       - schema_version should be present
    4. Return ValidationResult

    `validate_document_gt(data: dict, profile: GTProfile | None = None) -> ValidationResult`:
    1. Schema validation against DocumentGT JSON Schema
    2. If profile provided:
       - Semantic element types must be in profile.semantic_types (warn on unknown)
       - If formatting elements present and profile.formatting_types is empty, warn
    3. Structural checks:
       - document_id present
       - schema_version present
       - Relationship IDs reference existing element IDs (warn on dangling refs)
    4. Return ValidationResult

    `validate_gt_file(file_path: Path, profile: GTProfile | None = None) -> ValidationResult`:
    - Load JSON file
    - Detect if page-level (has "regions") or document-level (has "document_id")
    - Route to validate_page_gt or validate_document_gt
    - Return ValidationResult
