    - `SCHEMA_VERSION = "1.0.0"` constant

    - `MIN_SUPPORTED_VERSION = "1.0.0"` for backward compat checking

    **scholargt/schema/labels.py**: All label enums using `str, Enum` pattern so they serialize as strings in JSON.

    Spatial labels (17 values): `text_block`, `footnote_area`, `endnote_area`, `page_header`, `page_footer`, `page_number`, `section_header`, `title`, `block_quote`, `list_item`, `table`, `figure`, `caption`, `formula`, `marginal_note`, `bibliography_area`, `footnote_continuation`

    Semantic types (9 values): `footnote`, `endnote`, `citation`, `bibliography_entry`, `section`, `sous_rature`, `cross_reference`, `marginal_reference`, `page_number_annotation`

    Formatting types (6 values): `bold`, `italic`, `underline`, `strikethrough`, `small_caps`, `superscript`

    Document types (5 values): `metadata`, `toc`, `front_matter`, `back_matter`, `note_schema`

    Quality labels: `scan_quality` (low/medium/high), `difficulty` (easy/medium/hard)

    Citation types (7 sublabels): `author_date`, `numeric`, `abbreviated`, `footnote_style`, `stephanus`, `bekker`, `ak_reference`

    Marginal reference types (4 sublabels): `stephanus`, `bekker`, `akademie`, `custom`

    **scholargt/schema/base.py**: Core base models using Pydantic BaseModel.

    `BBox(BaseModel)`:
    - Fields: `x0`, `y0`, `x1`, `y1` (all `float`, ge=0.0, le=1.0 for normalized coords)
    - Method: `to_xywh() -> tuple[float, float, float, float]` for CryptOfCogito compat
    - Method: `area() -> float`
    - Validator: ensure x1 >= x0 and y1 >= y0

    `VerificationRecord(BaseModel)`:
    - Fields: `reviewer_id: str`, `timestamp: datetime`, `confidence: float` (ge=0.0, le=1.0), `notes: str | None = None`

    `GTElement(BaseModel)`:
    - Fields: `id: str`, `verifications: list[VerificationRecord] = Field(default_factory=list)`, `tags: list[str] = Field(default_factory=list)`
    - Method: `is_verified(threshold: float = 0.8) -> bool` — True if any verification.confidence >= threshold
    - Method: `agreement_score() -> float | None` — mean confidence across verifiers, None if no verifications
    - Config: `model_config = ConfigDict(extra="allow")` for forward compatibility per user decision

    **tests/test_scholargt/test_schema_base.py**: Tests for:
    - BBox creation, validation (x1 >= x0), to_xywh(), area()
    - VerificationRecord creation with all fields
    - GTElement creation, is_verified with different thresholds, agreement_score
    - GTElement with extra="allow" accepts unknown fields
    - Round-trip JSON serialization: model_dump_json() → model_validate_json()
    - Label enum serialization (enums serialize as strings in JSON)

  <action>
    **scholargt/schema/spatial.py**: Region model for page-level spatial annotations.

    `Region(GTElement)`:
    - `label: SpatialLabel` — spatial type (where on page)
    - `bbox: BBox` — normalized bounding box [x0, y0, x1, y1]
    - `text: str | None = None` — transcribed text content (optional, depends on profile)
    - `text_anchors: list[str] = Field(default_factory=list)` — notable text spans within region
    - `semantic_labels: list[SemanticType] = Field(default_factory=list)` — semantic meaning (independent dimension per user decision)
    - `reading_order_index: int | None = None` — position in reading order (optional)

    This model enforces the multi-dimensional label principle: `label` (spatial) and `semantic_labels` (semantic) are independent. A region can be `label="text_block"` with `semantic_labels=["footnote"]`.

    **scholargt/schema/page.py**: PageGT model for page-level ground truth files.

    `PageQuality(BaseModel)`:
    - `scan_quality: Literal["low", "medium", "high"] | None = None`
    - `difficulty: Literal["easy", "medium", "hard"] | None = None`

    `PageGT(BaseModel)`:
    - `schema_version: str = SCHEMA_VERSION` — references schema version per user decision
    - `page_index: int` — 0-based PDF page index
    - `page_label: str | None = None` — printed page number (e.g., "127", "xiv")
    - `dimensions: dict[str, float] | None = None` — {"width": 612, "height": 792}
    - `regions: list[Region] = Field(default_factory=list)` — spatial annotations
    - `reading_order: list[str] = Field(default_factory=list)` — ordered list of region IDs
    - `quality: PageQuality | None = None` — page quality metadata
    - `verifications: list[VerificationRecord] = Field(default_factory=list)` — page-level verifications
    - Config: `model_config = ConfigDict(extra="allow")`

    Validator on PageGT: `reading_order` IDs should be subset of `regions` IDs (warn, don't error — annotation may be in progress).

    **tests/test_scholargt/test_page_models.py**: Tests for:
    - Region creation with spatial label and independent semantic_labels
    - Region inherits GTElement verification methods
    - PageGT creation with regions and reading order
    - PageGT schema_version defaults to SCHEMA_VERSION
    - PageGT round-trip: model_dump_json() → model_validate_json() preserves all data
    - Multi-dimensional labeling: Region with label="text_block" and semantic_labels=["footnote"]
    - PageGT with extra fields (forward compat)
    - Reading order validation (IDs reference existing regions)
  </action>
